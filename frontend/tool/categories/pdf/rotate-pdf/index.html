Nexauren Rotate PDF FAQ

Can I rotate all pages in a PDF?

Yes. Choose all pages and select the rotation angle.

Can I rotate only selected pages?

Yes. A custom page-range option is available.

Which rotation angles are available?

The interface provides 90°, 180°, and 270° rotation.

Does this change my original PDF?

No. A new rotated PDF is exported.
