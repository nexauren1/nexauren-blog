Color Palette Extractor FAQ
Is the image uploaded?
No. Palette analysis is performed locally in your browser.
Can I copy individual HEX colors?
Yes. Each palette swatch has a button for copying its HEX value.
Can I export CSS and JSON?
Yes. The generated palette can be copied or downloaded as CSS variables and JSON.
How accurate is the palette?
The result is an approximate dominant-color palette based on sampled rendered pixels, not a perceptual color-science measurement.
