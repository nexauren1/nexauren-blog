Image Borders FAQ

Does export keep the original image resolution?

Yes. The source image is rendered at its original pixel dimensions; the frame is added around it.

Can the frame be transparent?

Yes. Enable Transparent outer frame and choose PNG or WebP when you need transparency.

Can I use JPG?

Yes. JPG exports use the selected background color for transparent areas.
