Before & After FAQ

Can the images have different dimensions?

Yes. The tool places both images on a common output canvas using the selected fit mode.

Can I move the split on mobile?

Yes. Use the range slider below the preview; it is designed for touch input.

Does export keep the source resolution?

The comparison is rendered using a calculated output canvas based on the larger source dimensions, subject to device memory limits.
