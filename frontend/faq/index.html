NEXAUREN · HELP CENTER

Frequently asked questions.

Clear answers about the tools, file processing, privacy, downloads, accounts, and common Nexauren workflows.

Are Nexauren tools free?

The public catalog includes free tools. Some account or premium features may have different access requirements.

Are files processed locally?

Many Image and PDF tools process files directly in the browser. A requested download or transfer may use temporary storage when needed.

Do you keep my original files?

The tools are designed to avoid unnecessary storage of original files. Check the individual tool page for any temporary transfer step.

Which file types are supported?

Support varies by tool. Each individual tool page lists the formats it accepts and exports.

Can I use Nexauren on a phone?

Yes. The catalog and tools are designed for mobile browsers as well as desktop browsers.

What happens when processing fails?

Tools show an error state and, where possible, keep the last valid result so a temporary processing problem does not erase usable output.

Where are the legal policies?

See Privacy, Terms, and Cookies for the current policies.

How many tools are available?

Nexauren currently has 26 active tools across two categories: Image and PDF.

Ready to use a tool?

Open the catalog and choose Image or PDF.
